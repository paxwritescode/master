\begin{frame}{Введение}
	
	\begin{itemize}
		\item Во многих задачах математической физики аналитическое решение ОДУ отсутствует, поэтому используются численные методы.
		
		\vspace{0.3cm}
		
		\item Методы Рунге--Кутты обеспечивают высокую точность, однако построение схем высокого порядка связано со сложной настройкой коэффициентов.
		
		\vspace{0.3cm}
		
		\item Для задач с осциллирующими решениями существенное влияние оказывает фазовая ошибка, что требует специальных подходов к выбору параметров метода.
		
		\vspace{0.3cm}
		
		\item Использование параметрических методов Рунге--Кутты позволяет подбирать коэффициенты посредством решения задачи оптимизации.
	\end{itemize}
	
\end{frame}
