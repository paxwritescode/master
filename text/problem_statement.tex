\subsection{Математическая модель задачи}
Ставится задача численного решения задачи Коши для системы обыкновенных дифференциальных уравнений (ОДУ) вида:
\begin{equation} \label{eq:Cauchy}
	\begin{cases}
		u'(t) = f(t, u) \\
		u(0) = u_0 \\
		t \in [0, T]
	\end{cases},
\end{equation}
где $u(t) \in \mathbb{R}^m, \; f:[0, T] \times \mathbb{R}^m \rightarrow \mathbb{R}^m$ — заданная достаточно гладкая функция.
 
 Предполагается, что решения класса задач \eqref{eq:Cauchy} $u(t)$ обладают осциллирующим характером.
 
 % тут дополнить - логический переход, описать набор типовых (тестовых) задач
 
Для построения и анализа методов и их оптимизации формируется набор типовых, или тестовых, задач с известным характером решения, подробно описанных в разделе \ref{sec:literature_and_theory}, на которых будет проводиться минимизация ошибки численной схемы. В рамках данной работы они представляются в виде двух следующих систем.

Первой моделью выступает тестовая линейная система, или гармонический осциллятор, позволяющий оценивать фазовые и диссипативные свойства численной схемы. Модель описывается линейным дифференциальным уравнением второго порядка:
\begin{equation*}
	\begin{cases}
		y''(t) + \omega^2 y(t) = 0 \\
		y(0) = y_0 \\
		y'(0) = y_0'
	\end{cases};
\end{equation*}
где $\omega$ - характерная частота осцилляций. Перед применением явных методов Рунге-Кутты данная задача Коши сводится к эквивалентной автономной системе первого порядка вида \eqref{eq:Cauchy}. Обозначим вектор состояния за $u(t) = [u_1(t), u_2(t)]^T = [y(t), y'(t)]^T \in \mathbb{R}^2$, после чего получим матричную форму:
\begin{equation*}
	u'(t) = A_{osc} \cdot u(t),
\end{equation*}
где матрица системы $A_{osc}$ имеет размерность $2 \times 2$ и записывается в виде 
\begin{equation*}
	A_{osc} = 
	\begin{bmatrix}
		0 & 1 \\
		- \omega^2 & 0
	\end{bmatrix}.
\end{equation*}
Поскольку для данной системы точное аналитическое решение известно, она позволяет вычислить глобальную ошибку метода в явном виде в любой точке сетки.

Следующей моделью является дискретизованное нелинейное уравнение Шрёдингера (NLS) как нелинейная система высокой размерности. Данная тестовая задача используется для тестирования, оптимизации параметров и оценки качества метода. Путём применения пространственной дискретизации и последующего разделения вещественной и мнимой частей данное (2 + 1)-мерное нелинейное уравнение сводится к многомерной системе вещественных ОДУ:
\begin{equation*}
	\begin{cases}
			u'_{NLS}(t) = F_{NLS}(t, u_{NLS}) \\
			u_{NLS}(0) = u_{0, NLS} \\
			t \in [0, T]
	\end{cases},
\end{equation*}

 Для численного интегрирования сформулированных выше тестовых систем применяется явный метод Рунге-Кутты порядка $p = 6$ с числом стадий $s = 8$, предложенный в \cite{Anastassi2023}. Как показано в подразделе \ref{subsec:about_RK}, аналитическое разрешение недоопределённой системы из 44 нелинейных условий позволяет выразить все элементы таблицы Бутчера \eqref{eq:Butcher_tableau} через вектор свободных параметров $\theta$:
 \begin{equation*}
 	\theta = (c_2, c_4, c_5, c_7) \in \mathbb{R}^4.
 \end{equation*}
 
 Таким образом, каждому значению параметра $\theta \in \mathbb{R}^4$ соответствует конкретный метод Рунге-Кутты с коэффициентами $(A(\theta), b(\theta), c(\theta))$. Для каждого значения параметра $\theta$ вычисляется ошибка численного решения на наборе тестовых задач.
 
 \subsection{Постановка задачи оптимизации}
% 1) качество метода оценивается по глобальной ошибке, ошибка зависит от theta
Рассматривается параметрическое семейство явных методов Рунге-Кутты шестого порядка с коэффициентами, зависящими от параметра $\theta \in \mathbb{R}^4$. Для фиксированной тестовой задачи и фиксированного шага интегрирования $h$ глобальная ошибка зависит от параметров $\theta$:
\begin{equation*}
	E = E(\theta, h).
\end{equation*}
Требуется определить такие значения параметров $\theta$, при которых ошибка численного решения минимальна.
% 2) функционал качества
Для количественной оценки качества метода (другими словами, для оценки ошибки) вводится функционал $C(\theta)$, который характеризует величину глобальной ошибки численного решения на наборе тестовых задач. В соответствии с \cite{Anastassi2025} функционал определяется как усреднённая относительная ошибка:
\begin{equation*}
	C(\theta) = \frac{1}{N} \sum_{i=1}^{N}
	\frac{\|E_i(\theta)\|_\infty}{\|\bar{E}_i\|_\infty},
\end{equation*}
где $E_i(\theta)$ - глобальная ошибка исследуемого метода на $i$-й тестовой задаче, а $\bar{E}_i$ — ошибка эталонного метода.
Таким образом, задача оптимизации коэффициентов метода принимает вид
\begin{equation*}
	\theta^* =
	\arg\min_{\theta \in \Omega} C(\theta),
\end{equation*}
% 3) допустимое множество параметров
где $\Omega \subset \mathbb{R}^4$ — множество допустимых параметров метода, для которых корректно определены коэффициенты таблицы Бутчера.
% 4) финал главы
Полученная задача минимизации решается численными методами безградиентной оптимизации. В рамках данной работы рассматривается применение эволюционного алгоритма для поиска оптимальных коэффициентов параметрического метода Рунге-Кутты.
