\section{\centering ПОСТАНОВКА ЗАДАЧИ}
%постановка задачи - уравнение, параментрические функции, надо вывести коэффициенты исходя из решения типовых задач
% \label{sec:problem_statement}
Основной задачей данной работы является построение оптимальных коэффициентов расчётной схемы для численного решения задачи Коши для ОДУ \eqref{eq:ODE} с осциллирующим характером поведения решения.

Для интегрирования системы \eqref{eq:ODE} применяется параметрическое семейство явных 8-стадийных методов Рунге-Кутты шестого алгебраического порядка точности. Как описано в подразделе~\ref{subsec:about_RK}, аналитическое разрешение недоопределённой системы уравнений порядка позволяет выразить все коэффициенты таблицы Бутчера через вектор свободных параметров $\theta$:
\begin{equation*}
	\theta = (c_2, c_4, c_5, c_7) \in \Omega \subset \mathbb{R}^4,
\end{equation*}
где $\Omega$ - допустимое множество параметров, заданное геометрическим ограничением монотонности искомых коэффициентов:
\begin{equation*}
	\Omega = \left\{ \theta \in [0, 1]^4: c_2 \leqslant c_4 \leqslant c_5 \leqslant c_7 \right\}.
\end{equation*}

Следовательно, фиксированному вектору параметров $\theta$ соответствует уникальный набор коэффициентов метода $(A(\theta), b(\theta), c(\theta))$. Необходимо вывести оптимальные значения параметров $\theta^*$ исходя из минимизации погрешности системы целевыми функциями \eqref{eq:functional}, \eqref{eq:alternativе_functional} на репрезентативном наборе задач, подробно описанных в подразделе~\ref{subsec:representative_problems}. 

Таким образом, итоговая математическая постановка задачи вывода оптимальных коэффициентов таблицы Бутчера формулируется как задача скалярного глобального поиска:
\begin{equation*}
	\theta^* = \arg\min_{\theta \in \Omega} C(\theta).
\end{equation*}
